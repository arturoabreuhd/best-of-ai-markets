> **Why this list is different.** Most awesome-lists are hand-maintained snapshots that go stale within months. This one is **discovered by metadata _and_ by code** (so tools without the right GitHub topic still get found) and **re-scored weekly** from live signals. Health and activity are visible on every entry.

> 🔎 **Looking for the few I actually use, with methodology?** This is the wide net — _every tool we see value in_. The hand-picked, epistemically-vetted shortlist lives separately as **Emergence Picks** _(link coming)_.

## Explanation
- 🥇🥈🥉&nbsp; Combined project-quality score
- ⭐️&nbsp; Star count from GitHub
- 🐣&nbsp; New project _(less than 6 months old)_
- 💤&nbsp; Inactive project _(6 months no activity)_
- 💀&nbsp; Dead project _(12 months no activity)_
- 📈📉&nbsp; Project is trending up or down
- ➕&nbsp; Project was recently added
- ❗️&nbsp; Warning _(e.g. missing/risky license)_
- 👨‍💻&nbsp; Contributors count from GitHub
- 🔀&nbsp; Fork count from GitHub
- 📋&nbsp; Issue count from GitHub
- ⏱️&nbsp; Last update timestamp on package manager
- 📥&nbsp; Download count from package manager
- 📦&nbsp; Number of dependent projects
